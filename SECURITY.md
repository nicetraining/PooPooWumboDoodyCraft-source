# Security policy

Do not publish exploits, private data, access tokens, malicious files, or world data in a public issue.

Report security problems privately to the repository owner and include:

- affected version;
- reproduction steps;
- expected and observed impact;
- relevant logs with personal data and tokens removed.

The port intentionally excludes legacy behavior that deleted JAR files, generated scripts, terminated Java processes, or loaded arbitrary unvalidated models.
